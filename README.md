# Mental Math · web pages

The public pages for the Mental Math iPhone and iPad apps (Mental Math for Learners and Mental Math for Teachers),
served by GitHub Pages at https://mentalmath.dailynumbergames.com:

- `privacy.html`: privacy policy (both apps)
- `support.html`: support and FAQ (both apps)
- `index.html`: links to both

The pages are generated: edit the text in `make_pages.py`, then run `python make_pages.py`.
